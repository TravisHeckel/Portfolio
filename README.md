# Portfolio Website

My personal portfolio site — a responsive single-page website introducing me, my
background, and my work as a full-stack software developer.

## Features

- **Full-screen background video** hero with an intro and a favorite quote
- **Image slideshow** highlighting my skills (HTML/CSS/JavaScript, Python, C#/.NET,
  SQL, Django), with arrow and dot navigation
- **About** and **GitHub** sections
- **Pop-up contact form** wired to [Formspree](https://formspree.io/) for email delivery
- Links to my resume, LinkedIn, and Instagram

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or build step — it's a static site.

## Running it locally

Clone the repo and open the page in a browser:

```bash
git clone https://github.com/TravisHeckel/Portfolio.git
cd "Portfolio/Portfolio website"
# then open index.html in your browser
```

> Note: the contact form uses Formspree and only submits when the site is served
> over the internet (a live host), not from a local file.
